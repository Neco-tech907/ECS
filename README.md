# ESC-Project

Учебный проект на Unity 6000.3, URP и DOTS/ECS. Пастух загоняет стадо овец в загон, на стадо выходят волки.

Открывать `Assets/Scenes/SampleScene.unity` в редакторе `6000.3.10f1`. Подсцена `Assets/Scenes/HerdSubScene.unity` подхватывается сама.

Управление в игре: WASD и мышь — пастух, Q — свисток, F или левая кнопка мыши — камень. Коричневая площадка запускает волны волков.

Материалы к практикам лежат в `Docs/`.
