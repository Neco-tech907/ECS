# ESC-Project

Ветка `pr1` — минимум первой практики на Unity 6000.3, URP и DOTS/ECS.

Овцы идут к загону. Здоровье не выше нуля включает `Dead`, и такая овца останавливается. Стамина тратится на ходу и плавно восстанавливается; при нуле овца стоит, пока запас не вернётся хотя бы до половины.

Открывать `Assets/Scenes/SampleScene.unity`. Овцы и загон лежат в подсцене `Assets/Scenes/HerdSubScene.unity`. У `Sheep_0` здоровье равно 0, поэтому она не идёт.
